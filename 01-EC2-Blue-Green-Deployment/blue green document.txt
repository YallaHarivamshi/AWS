Setting up HTTPS for your Application:
======================================
How to create HTTPS certificates in AWS?

Go to ACM Service
Click on Request Certificate
Select Request a Public Certificate --> Next
Provide Domain Name : Ex : *.boom.com [First you need to purchase domain in R53]
Click on the Certificate and Create records in R53. (Make sure
you purchase the domain first and then create record)

Go to Load Balancer --> Listeners and Rules --> Add listener --> select httpd 443 --> From ACM --> Select Certificate

AWS will auto -renew the certificate every year
If any certificate is imported into ACM, you need to renew it manually
