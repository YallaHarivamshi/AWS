What is Node.js?
-----------------

Node.js is a JavaScript runtime environment that allows you to run JavaScript outside the browser, primarily on servers.

Before Node.js, JavaScript could only run inside web browsers like Chrome, Firefox, or Edge.

With Node.js, you can build:
------------------------
Web servers
REST APIs
Real-time chat applications
Streaming applications
Microservices
CLI tools
Automation scripts


Why was Node.js created?
------------------------
Before Node.js:-
--------------
Frontend → HTML, CSS, JavaScript
Backend → Java, PHP, Python, .NET, Ruby

Developers had to learn two different languages.

Node.js allows JavaScript to be used on both the frontend and backend.

What does Node.js contain?
-------------------------
A Node.js application typically consists of:

V8 JavaScript Engine
Event Loop
NPM (Node Package Manager)
Express.js (most common framework)


V8 JavaScript Engine : Google Chrome's JavaScript engine. It converts JavaScript into machine code.

Event Loop: Node.js uses an event-driven architecture.Instead of creating one thread per request, it handles many requests 
             asynchronously. This is why Node.js is very fast.

NPM (Node Package Manager): NPM is the world's largest software package repository. Install packages like:
express
mongoose
axios
react
socket.io
jsonwebtoken

Example: npm install express

Express.js (most common framework): Node.js is the runtime. Express.js is a framework built on top of Node.js for creating web servers and APIs.

Install Nginx and configure as Reverse proxy
-----------------------------------------

Nginx sits between users and your backend servers, receives client requests, and forwards them to the correct internal application server.

Without Reverse Proxy: Problems: 
--------------------------------
Node.js exposed directly to internet
No SSL handling
Hard to manage multiple apps
Less secure
Poor scalability

With Nginx Reverse Proxy: User → Nginx → Node.js
---------------------------
Nginx becomes the public-facing server.
Node.js stays private internally.

Browser
   ↓
Nginx (Port 80/443)
   ↓
Node.js (Port 3000)
   ↓
Redis / RDS

Why Called "Reverse" Proxy?
--------------------------
Normal proxy is  : Client → Proxy → Internet
Reverse Proxy: Internet → Reverse Proxy → Backend Servers

Nginx reverse proxy is a server that sits between clients and backend applications, forwarding requests to internal servers while providing security, SSL termination, load balancing, and high performance

sudo dnf install nginx -y

sudo systemctl enable nginx
sudo systemctl start nginx

Configure Nginx for Frontend
---------------------------
sudo rm -rf /usr/share/nginx/html/*

Copy React build:
sudo cp -r build/* /usr/share/nginx/html/


Configure Reverse Proxy
----------------------
sudo vi /etc/nginx/conf.d/app.conf

server {

    listen 80;

    server_name _;

    root /usr/share/nginx/html;

    index index.html;

    location / {

        try_files $uri /index.html;
    }

    location /api/ {

        proxy_pass http://127.0.0.1:3000/;

        proxy_http_version 1.1;

        proxy_set_header Upgrade $http_upgrade;

        proxy_set_header Connection 'upgrade';

        proxy_set_header Host $host;

        proxy_cache_bypass $http_upgrade;
    }
}


sudo rm -f /etc/nginx/conf.d/default.conf

sudo nginx -t

sudo systemctl restart nginx
